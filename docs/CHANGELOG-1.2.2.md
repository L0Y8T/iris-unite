# Iris Unite 1.2.2

1.2.1 加了顶层「学习模式」按钮，但点下去只是换了配置和按钮高亮，页面还是聊天页——
所以看起来仍然像「点了没反应」。这一版给它一整页。

## 这一版

| 项 | 说明 |
|---|---|
| 学习模式有独立页 | 点按钮直接换页：大标题、主题输入、可选的「目前水平 / 想达到的程度 / 已掌握的概念」、四步流程说明、最近的学习计划。聊天输入区在这一页收起 |
| 选中态看得见 | 三个模式按钮的选中样式改成品牌色实心（浅色主题近黑、深色主题近白，文字自动反色），不再是一点点阴影差别 |
| 提交直接开跑 | 填完点「生成学习计划」会切回聊天页、把主题作为这一轮的用户消息发出去；档位自动是学习档 |
| 手填三项等价于一次问诊 | 水平 / 目标 / 已掌握走和「课前问诊」同一个归并入口，写进 `teaching.intake`，后面所有提示词读到的仍是同一份结论 |
| 修一个高亮 bug | 没有打开的对话时，切换只改了草稿没落进 `state.researchConfig`，于是页面换了、按钮还停在原来那个 |

## 构建说明

资产 `IrisUnite-1.2.2-win32-x64.zip` 解压后直接运行 `IrisUnite.exe`，无需安装。

## 验证

- `npm test`：416 项全过。
- `npm run test:all -- --skip-live`：**18 项全过**（新增「学习模式独立页」一条：点按钮必须换页、
  选中态背景必须与未选中不同、提交后这一轮必须是 `p2-teach` 且手填的水平写进问诊摘要）。
- 打包产物实测：点「学习模式」→ 页面切到学习页、按钮实心高亮、提交后主题成为第一条用户消息。
