# Iris Unite 1.2.1

1.2.0 里学习档已经能跑，但**界面上找不到**：它藏在科研配置面板的「档位」里，名字叫「教学」，
输入框上方只有「科研模式 / 对话」两个按钮。装好 1.2.0 后找不到学习模式，是预期内的结果，不是安装问题。

## 修了什么

| 问题 | 修法 |
|---|---|
| 顶层没有「学习模式」入口 | 输入框上方改成三个按钮：**科研模式 / 学习模式 / 对话**。「学习模式」= 科研模式 + 档位「学习」的快捷入口，底层 mode 仍只有 `research` / `standard`，账本、历史、运行器、校验都不用改 |
| 档位名写的是「教学」 | 界面显示改成「学习」，内部 id 仍是 `p2-teach`（预算公式与三个环节 id 都挂在它上面，改名没有收益） |
| 从学习档切回科研模式会静默失败 | 切档时没有关掉 `experiments.enabled`，保存被校验拒绝（「学习档不支持自动实验」），界面上只闪一句 toast、按钮看起来没反应。现在与配置面板的处理一致 |
| 没打开过配置面板就切档会崩 | `collectResearchForm()` 强依赖面板 DOM，缺元素时抛错。改成缺输入框就保留原值 |
| 环境里带 `ELECTRON_RUN_AS_NODE=1` 时所有界面验收都跑不起来 | 该变量会让 electron 退化成纯 Node，`main.cjs` 第一行 `app.setName` 就炸，现象是「渲染进程没有起来」。测试工具与验收脚本现在统一摘掉它 |

顺带把发布脚本的取令牌方式收紧：只认 `GITHUB_TOKEN` 环境变量，不再读本机 Git 凭据
（仓库卫生检查把那条命令列为禁止模式，历史上真有一个读凭据的调试脚本混进过公开仓库）。

## 界面现在长这样

- 按钮：科研模式 / **学习模式** / 对话；同一时刻只有一个亮，按「模式 + 档位」算。
- 选中学习模式后：输入框占位提示改成「写下想学的主题与目标」，输入区芯片直接列出
  知识点拆解 / 分阶段计划 / 自测题设计 / 反证与整合。
- 回复底部标注「学习模式」，不再是笼统的「科研模式」。
