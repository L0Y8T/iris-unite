# Iris Unite 0.5 interface

## Iris Unite additions

- Rename the visible product and packaged application to Iris Unite. Use the supplied iris SVGs and Windows ICO unchanged, with light/dark variants following the theme.
- Preserve the DSH-inspired workspace sidebar and monochrome reading canvas. Group each concrete model name with its enabled state and an independent Power trigger; native range, keyboard input and exact effort labels share the same state.
- Add settings-based model connections, with OpenAI-compatible or Claude Messages formats, explicit effort capability, encrypted credentials, connection testing and enabled state. The participant picker supports up to six enabled models and retains the 2.5-second last-model toast.
- Research configuration follows project/5122.jpg: GPT Medium orchestration, independently configurable parallel research tasks, then GPT XHigh counterargument review. Task cards expose model, strength and research responsibility; the composer always shows the concrete role assignments.
- Show actual research phases and call counts. Public working materials are collapsed by default and the answer contains only the final deliverable. Refinement is bounded by the selected call budget; stages that are skipped are marked explicitly.
- Verify both themes, keyboard and focus behavior, connection encryption, model-specific effort payloads, a live GPT/DeepSeek research run, narrow layouts, and restart persistence in the installed Windows package. Test fixture profiles remain in isolated test data.

Design read: preserve the existing monochrome desktop product, refine its DSH-inspired navigation and Codex-inspired model controls. This is a working conversation interface, so Taste's frontend-ui-engineering workflow leads; marketing-page layouts are out of scope.

Design variance 3, motion intensity 3, visual density 5: predictable navigation and a reading-first canvas, with motion only for user feedback and genuine running state.

## Audit of 0.3

- Preserve: Duet wordmark, workspace tree and assignments, history view, model names and Power range, single final answer, collapsed public collaboration records.
- Improve: repeated workspace navigation, very small pale text, wide scattered chat layout, identical hierarchy across buttons, minimal Markdown support, no persistent appearance preference, and no focus return from the model popover.
- Functional contracts: existing element IDs, history sources, model selection guard, per-conversation settings, stage events and stored data stay compatible. No API or cooperation behavior is redesigned.

## Tokens and rules

- Neutral light/dark themes only. Semantic surface, text, border, focus and state tokens. Default follows the system; explicit theme preference persists.
- Palette, type and geometry now come from DeepSeek Desktop's design-platform tokens: cool "bluish" neutrals (`#0f1115` label primary, `#f9fafb` sidebar, `#151517` dark canvas, `#1b1b1c` dark sidebar), alpha hairlines instead of grey rules, near-black brand with blue reserved for links and the active tab (`#2563eb` light / `#679efe` dark), `#edf3fe` user-bubble tint.
- Text greys are darker than DeepSeek Desktop's own tertiary tier so every tier clears WCAG AA on the darkest common surface: `#61666b` 4.9:1, `#63686e` 4.8:1, `#666b71` 4.6:1 on `#ebeef2`; dark tiers `#cfd3d6`, `#b4b9bf`, `#b0b5bb`. Hierarchy is carried by size and weight, not by sub-AA contrast.
- DeepSeek font stack (`-apple-system`, `Segoe UI`, `PingFang SC`, `Microsoft YaHei`) with a 12 / 13 / 14 px UI scale and 14px/24px reading body. Compressed heading ladder: h1 21/30 700, h2 19/28 700, h3 18/26 700, h4 14/24 600; 16px paragraph rhythm, 18px list indent, 6px list gap.
- Spacing: 4, 8, 12, 16, 20, 24, 32, 40, 48 px. Reading column 860px. Composer shares that alignment.
- Radii: 6px inline code and ticks; 8px inputs; 12px sidebar controls; 16px cards; 20px popovers and dialogs; 22px user bubble; capsule (999px) for buttons, model chips, mode switch and tag pills. Only the send button is a true circle.
- Elevation: `.5px` stroke plus the light/large shadow pair (`--elevation-panel`, `--elevation-prominent`) on popovers, menus and dialogs.
- Iris Unite wordmark and supplied iris mark. Official Tabler outline icons at a consistent 1.6px stroke, selected SVGs generated by scripts/prepare-ui.cjs with license attribution.
- Layers: base 0, sidebar drawer 10, drawer scrim 9, model popover 20, toast 30, native dialog top layer.
- Transition: 200ms cubic-bezier(.4,0,.2,1); reduced-motion disables nonessential animation. No decorative motion.
- Stylesheets stack as tokens.css, styles.css, premium.css, iris.css, dsh.css. The last sheet is the DeepSeek Desktop alignment layer; add new design work there rather than re-tuning the earlier sheets.

## Interaction and verification

- Accessible native range and advanced selects, visible focus, Escape-to-close and focus return; two independent model selections retain the last-model guard.
- Five-stage progress uses real stage events, never a fabricated percentage or time estimate.
- Collapsed public collaboration notes remain collapsed by default. Markdown uses Marked with DOMPurify; raw HTML is escaped, external HTTP(S) links open only on user click, and table headings are semantic.
- Native desktop minimum size remains supported; narrow renderer layouts use a dismissible sidebar drawer and wrapped model controls. Theme, selection, text wrapping, long answers, error and empty states are checked in both modes.
- Test with real saved cooperation records in isolated test data; no demo mode or invented records are added to user data.
